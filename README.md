# YouTube Clone

Clon visual de la página principal de YouTube desarrollado como práctica de maquetación web con HTML y CSS.

El proyecto reproduce elementos principales de la interfaz de YouTube, incluyendo la barra de navegación, buscador, menú lateral, categorías y una cuadrícula de videos.

## Tecnologías

- HTML5
- CSS3
- Font Awesome
- Google Fonts

## Características

- Barra de navegación superior.
- Buscador inspirado en YouTube.
- Menú lateral con accesos principales.
- Categorías de contenido.
- Tarjetas de videos con:
  - Miniatura.
  - Canal.
  - Título.
  - Visualizaciones.
  - Fecha de publicación.
- Enlaces hacia videos reales de YouTube.
- Diseño inspirado en la interfaz original de YouTube.
